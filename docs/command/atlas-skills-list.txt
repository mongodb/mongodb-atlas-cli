=================
atlas skills list
=================

.. default-domain:: mongodb

.. contents:: On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

List MongoDB agent skills and plugins available upstream.

List the standalone MongoDB agent skills and bundled mongodb-atlas plugin available for Claude Code or Codex.

Syntax
------

.. code-block::
   :caption: Command Syntax

   atlas skills list [options]

.. Code end marker, please don't delete this comment

Options
-------

.. list-table::
   :header-rows: 1
   :widths: 20 10 10 60

   * - Name
     - Type
     - Required
     - Description
   * - -h, --help
     - 
     - false
     - help for list
   * - -o, --output
     - string
     - false
     - Output format. Valid values are json, json-path, go-template, or go-template-file. To see the full output, use the -o json option.

Examples
--------

.. code-block::
   :copyable: false

   # List available MongoDB agent skills and plugins:
   atlas skills list

   
.. code-block::
   :copyable: false

   # List skills as JSON:
   atlas skills list --output json
